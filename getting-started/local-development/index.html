Local Development

Local Development

Use this page to set up the backend and frontend on a local machine.

Backend Setup

  1. Install dependencies:
  2. Run composer install in studern-backend.
  3. Copy environment file:
  4. Duplicate .env.example to .env if needed.
  5. Configure the database:
  6. SQLite is supported out-of-the-box.
  7. Run migrations:
  8. php artisan migrate
  9. (Optional) Seed data:
  10. php artisan db:seed
  11. Start the API server:
  12. php artisan serve

Queue Setup (Local)

  • Set QUEUE_CONNECTION=database in .env
  • Run queue migrations if needed:
  • php artisan queue:table
  • php artisan migrate
  • Start a worker:
  • php artisan queue:work

Frontend Setup

  1. Install dependencies:
  2. Run npm install in studern-frontend.
  3. Configure API base URL:
  4. Set VITE_API_BASE_URL in the frontend .env if needed.
  5. Start the dev server:
  6. npm run dev

Default URLs

  • Backend API: http://localhost:8000/api
  • Frontend: http://localhost:5173

Common Issues

  • Authentication failures usually come from missing or expired JWT tokens.
  • Posting jobs may require a payment package after the free posting is used.
  • Queue processing depends on QUEUE_CONNECTION (database is recommended for local dev).
