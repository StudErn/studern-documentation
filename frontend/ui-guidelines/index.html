UI Guidelines

UI Guidelines

This section documents the UI principles used across StudErn.

Design Goals

  • Clean, modern surfaces
  • Clear hierarchy and readable typography
  • Consistent spacing and color usage

Components

  • Primary actions use gradient buttons
  • Secondary actions use outlined buttons
  • Inputs use rounded corners with focus rings

Responsive Behavior

  • Sidebar collapses on smaller screens
  • Forms stack to a single column on mobile
  • Tables switch to card-like layouts where possible

Accessibility

  • Labels paired with inputs
  • Focus styles retained for keyboard users
  • Buttons include descriptive labels
