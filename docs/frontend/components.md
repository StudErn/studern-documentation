# Frontend Components

Key reusable components in the React UI.

## Layout

- AppLayout: authenticated layout with sidebar and header
- DashboardHeader: top bar with view and company switch
- DashboardSidebar: navigation for view roles

## Hiring

- HiringList: list view with filters
- CreateHiring: job/internship creation form

## Company

- MemberManagement: users, roles, permissions

## Utility

- ProtectedRoute: guards access based on auth and role
- ToastProvider: global notifications
